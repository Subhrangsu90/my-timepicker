Connecting a timepicker to an input

A timepicker is composed of a text input and a dialog overlay, connected through the ngxMatTimepicker binding on the input.

There is also an optional timepicker toggle button that gives the user an easy way to open the dialog.

HTML 
<input matInput [ngxMatTimepicker]="picker">
<ngx-mat-timepicker-toggle matIconSuffix [for]="picker"/>
<ngx-mat-timepicker #picker/>

The timepicker input and toggle can be used either on their own or as part of a mat-form-field:

Use with Angular Forms

The timepicker input implements ControlValueAccessor, allowing integration with Reactive Forms and template-driven forms.

TypeScript 
readonly timeControl = new FormControl('07:00 AM', [Validators.required]);

onSave(): void {
  if (this.timeControl.valid) {
    console.log('Selected Time:', this.timeControl.value);
  }
}

Integration with JavaScript Date Objects

When working with backend APIs or UTC timestamps, set valueType="date" on the input. The timepicker will automatically bind directly to a native JavaScript Date instance, updating its hours and minutes while preserving the date component and user timezone.

HTML 
<input [ngxMatTimepicker]="picker" [formControl]="dateControl" valueType="date">
<ngx-mat-timepicker-toggle [for]="picker"/>
<ngx-mat-timepicker #picker (dateSet)="onDateChange($event)"/>

Input validation

The timepicker validates typed text against the chosen time format. You can also enforce boundary constraints by configuring min and max attributes. 

<input [ngxMatTimepicker]="picker" min="09:00 AM" max="05:00 PM">

Customizing the dial options

The timepicker supports rich visual customizability:

  • 12-Hour vs. 24-Hour dial: Set [format]="24" to enable concentric 24-hour dials (1-12 outer, 13-24 inner).
  • Orientation: Use orientation="horizontal" for tablet and landscape widescreen displays.
  • Minute interval step: Configure [stepMinute]="5" or 15 to restrict selection to standard appointment increments.
  • Auto Advance: Enable [autoAdvance]="true" (default) to immediately transition to the minute dial after selecting an hour.

Customizing the toggle icon

By default, the timepicker toggle renders a Material clock icon. You can place any custom icon inside the toggle element: 

<ngx-mat-timepicker-toggle [for]="picker">
  <mat-icon ngxMatTimepickerToggleIcon>schedule</mat-icon>
</ngx-mat-timepicker-toggle>

Internationalization

Localize dialog labels (Select Time, Cancel, OK, Hour, Minute, AM/PM) by providing an instance of NgxMatTimepickerIntl or configuring the [locale] attribute.

Full bidirectional Right-to-Left (RTL) layout is supported out of the box when used inside elements with dir="rtl".

Accessibility

The timepicker implements WCAG 2.1 AAA accessibility standards:

  • Keyboard Navigation: Use Arrow keys (←, →, ↑, ↓) to increment and decrement dial hands.
  • Direct Numeric Input: Press the keyboard icon on the bottom-left of the dialog to switch to high-contrast numeric text inputs.
  • ARIA Attributes: Dialogs utilize role="dialog" and proper aria-label announcements for screen readers.

Troubleshooting

Error: CDK Overlay styles missing

Ensure @angular/cdk/overlay-prebuilt.css is imported in your global styles.scss file.

Timepicker dialog opens off-screen

Verify that your overlay container is not constrained by parent CSS overflow: hidden.

API reference for Angular Material Timepicker

Import the timepicker module or individual standalone directives:

TypeScript 
import {
  NgxMatTimepicker,
  NgxMatTimepickerInput,
  NgxMatTimepickerToggle,
  NgxMatTimepickerDialog,
  NgxMatTimepickerIntl
} from 'ngx-mat-timepicker';

Directive NgxMatTimepicker

Selector: ngx-mat-timepicker. Exports: ngxMatTimepicker.

The core popup component that displays the interactive Material 3 timepicker dialog.

Properties

Name Type Default Description
@Input() format 12 | 24 | '12h' | '24h' 12 Time format: 12-hour (with AM/PM) or 24-hour concentric dials.
@Input() orientation 'auto' | 'vertical' | 'horizontal' 'auto' Layout orientation (vertical portrait or horizontal landscape).
@Input() stepMinute number 1 Step interval for minute selection (e.g. 5, 10, 15).
@Input() autoAdvance boolean true Whether selecting an hour automatically advances view to minutes.
@Input() disabled boolean false Whether the timepicker interaction is disabled.
@Input() locale string 'en-US' Active locale code for numbers and text parsing.
@Output() timeSet EventEmitter<TimeValue> — Emits when the user confirms a time value.
@Output() dateSet EventEmitter<Date> — Emits full JavaScript Date object when a time is confirmed.
@Output() opened EventEmitter<void> — Emits when the timepicker overlay opens.
@Output() closed EventEmitter<void> — Emits when the timepicker overlay closes.

Methods

Signature Description
open(): void Opens the timepicker dialog.
close(): void Closes the timepicker dialog.

Directive NgxMatTimepickerInput

Selector: input[ngxMatTimepicker].

Connects an HTML input element with the timepicker and implements ControlValueAccessor.

Properties

Name Type Default Description
@Input() ngxMatTimepicker NgxMatTimepicker — The timepicker instance that the input is associated with.
@Input() valueType 'string' | 'date' 'string' Output type bound to the form control.
@Input() min string | TimeValue | Date — The minimum allowed time boundary.
@Input() max string | TimeValue | Date — The maximum allowed time boundary.

Component NgxMatTimepickerToggle

Renders a clickable toggle button that opens the attached timepicker popup.
