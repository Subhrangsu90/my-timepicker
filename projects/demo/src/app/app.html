API Reference

Complete reference documentation for directives, components, services, and tokens exported by ngx-material-timepicker.

Component

NgxMatTimepicker

The primary container that coordinates the timepicker overlay dialog, orientation, clock dial format, and value emission.

Inputs

Name Type Default Description
format '12h' | '24h' '12h' Determines whether time is selected in 12-hour AM/PM format or 24-hour military format.
orientation 'auto' | 'vertical' | 'horizontal' 'auto' Layout orientation of the dialog (portrait, landscape, or auto-detecting).
stepMinute number 1 Minute increment interval (e.g. 5, 10, 15, 30).
disabled boolean false Whether the timepicker dialog is disabled from opening.
theme string undefined Optional CSS class applied to the dialog overlay panel.

Outputs

Name Payload Description
timeSet TimeValue Emits when the user confirms a time by clicking OK or pressing Enter.
dateSet Date Emits an updated JavaScript Date object if connected to a Date value.
opened void Emits when the timepicker dialog opens.
closed void Emits when the timepicker dialog closes.
Directive

NgxMatTimepickerInput

Connects a text <input> element with an NgxMatTimepicker instance. Implements ControlValueAccessor for seamless reactive forms and signal forms.

Properties

Name Type Default Description
ngxMatTimepicker NgxMatTimepicker Required The timepicker instance that controls this input.
valueType 'auto' | 'string' | 'date' 'auto' Controls whether the input emits formatted strings or native Date instances.
timeChange output<string> — Emits formatted time string whenever user alters the time.
dateChange output<Date> — Emits updated Date instance whenever user alters the time.
Component

NgxMatTimepickerToggle

A Material button with clock icon that toggles opening the connected timepicker dialog. Place inside mat-form-field with matIconSuffix.

Name Type Default Description
for NgxMatTimepicker Required The timepicker instance opened by this toggle.
disabled boolean false Whether the toggle button is disabled.
Service

NgxMatTimepickerIntl

Internationalization service providing customizable labels, button texts, and aria-labels across any language.

Property Default (en-US) Description
selectTimeLabel 'Select time' Dial header title when in clock selection mode.
enterTimeLabel 'Enter time' Input header title when in keyboard entry mode.
hourLabel 'Hour' Aria label for hour selection.
minuteLabel 'Minute' Aria label for minute selection.
okLabel 'OK' Text on the dialog confirmation button.
cancelLabel 'Cancel' Text on the dialog cancellation button.
